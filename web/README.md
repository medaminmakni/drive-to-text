# Drive-to-Text web page

The Next.js page of the project (see the [main README](../README.md)). It covers the whole flow: folder link, file selection, extraction settings, live progress and results.

```bash
npm ci
npm run dev        # http://localhost:3000, forwards /api/... to http://localhost:8000
npm run lint       # ESLint
npx tsc --noEmit   # type check
npm run build      # production build ("standalone" output, used by the Docker image)
```

`API_URL` sets the backend address (default `http://localhost:8000`). It is read when the page is built, so the Docker image receives it as a build argument.

```
src/
  app/          layout (welcome animation, icon) and the single page
  components/   one component per part of the flow:
                AppHeader, Stepper, FolderForm, FileTable, ExtractOptions,
                ActionBar, BatchProgress, ResultList, Welcome, LogoMark, icons
  lib/          types.ts (the API contract in docs/API.md), api.ts (fetch + errors),
                useBatch.ts (starts a batch and polls it every second), format.ts
```

`AGENTS.md` is generated by Next.js 16 itself (`next dev` re-creates it).
